## 本次补齐的功能

- JSON 条目新增可选 `assessment`：`status` 区分 confirmed/inferred/partial/unknown，`basis` 区分 static/runtime/mixed/unverified，并支持 `scope`、`review` 和 `limitations`。旧数据库无需修改；省略字段时不会自动分级。

- 面板内普通点击 Markdown 笔记链接或自定义证据链接，可在当前面板继续查看，支持返回并恢复上次内容滚动位置。相对路径以当前证据文件为基准；附件和外部链接保留原有行为。
- 缺失关联笔记会提示错误，不会由插件请求创建新笔记。读取失败时仍可返回上一条证据。
- 长定位表格在表格内部横向滚动，单元格可换行，避免挤压整个浮动面板。
