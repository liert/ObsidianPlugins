# 示例函数详细证据

以下内容均为人为构造的演示。

## 长度上限

比较指令使用立即数 `0x1000`，即十进制 `4096`。`ja` 表示无符号“大于”，因此等于上限时不会进入拒绝分支。

```asm
cmp edi, 1000h
ja  reject
mov eax, 1
ret
reject:
xor eax, eax
ret
```

1. 观察：长度参数与 `0x1000` 比较。
2. 观察：仅在无符号大于时拒绝。
3. 推导：允许范围为 `0 ≤ length ≤ 4096`。

## 边界数据

演示预期结果：`4095 → 接受`、`4096 → 接受`、`4097 → 拒绝`。这些是演示数据，不能替代真实样本测试。 ^boundary
